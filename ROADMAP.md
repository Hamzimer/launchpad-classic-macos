# Launchpad Classic Roadmap

This roadmap describes likely areas of work, not guaranteed release dates. Priorities may change based on macOS updates, bug reports, and community contributions.

## Shipped

- Full-screen launcher with search and adaptive paging
- Mouse, wheel, trackpad, keyboard, and page-indicator navigation
- Folder creation, renaming, rearrangement, and removing apps from folders
- Automatic grouping of Apple Utilities
- Automatic discovery when applications are installed or removed
- Desktop and macOS wallpaper backgrounds
- English, Japanese, and Traditional Chinese
- Native macOS 26 Liquid Glass controls
- Signed Sparkle update feed with automatic download and installation
- Universal 2 release for Apple Silicon and Intel Macs

## Next

- Continue profiling launch time, memory use, and very large application libraries
- Expand automated accessibility and interaction coverage
- Improve diagnostics for application bundles that macOS refuses to enumerate
- Add more community-provided translations
- Publish a Homebrew Cask installation path

## Longer-term

- Apple notarization when a Developer ID distribution workflow is available
- Optional backup and restore for launcher layout data
- Additional keyboard organization workflows

Suggestions are welcome through the repository's feature-request template. Focused contributions marked as `good first issue` are especially welcome.
